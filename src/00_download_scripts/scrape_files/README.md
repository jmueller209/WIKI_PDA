# Downloading the necessary files for the project

In order to create the offline database, we use several database dumps and other files provided by [Wikimedia](https://dumps.wikimedia.org/). The following files are required:

1. **Wikidata Entity Database Dump**: This is the main database dump that contains metadata about all wikidata entities. An in depth documentation of the dump can be found [here](https://doc.wikimedia.org/Wikibase/master/php/docs_topics_json.html).
